# mt

## Purpose

The `mt` module identifies cells with unusually high mitochondrial RNA content, a common indicator of low-quality or stressed cells.

Mitochondrial outliers are detected independently within each sample using a median absolute deviation (MAD) approach. Cells identified as outliers are flagged but not removed at this stage.

The module generates a mitochondrial QC report and writes an updated AnnData object for downstream filtering.

## Inputs

- AnnData object generated by the `import` module
- Per-cell mitochondrial percentages (`pct_counts_mt`)
- Sample assignments (`sample`)

## Outputs

- `<input>_mtqc.h5ad`
- Mitochondrial QC figure
- Module manifest

## Main Functions

- Calculate sample-specific mitochondrial thresholds
- Identify mitochondrial outlier cells
- Store outlier calls in `adata.obs["mt_outlier"]`
- Record QC statistics in `adata.uns["mt_qc"]`
- Generate mitochondrial QC plots
- Create an updated AnnData object for downstream analysis

## Parameters

### Required Parameters

| Parameter | Description |
|------------|-------------|
| `--project_dir` | Root Scribble project directory. |
| `--input` | Input AnnData object, typically `combined.h5ad` from the import module. |

### Mitochondrial Thresholding

| Parameter | Default | Description |
|------------|----------|-------------|
| `--nmads` | 3 | Number of median absolute deviations (MADs) above the sample median used to define mitochondrial outliers. |

### Reproducibility

| Parameter | Default | Description |
|------------|----------|-------------|
| `--manifest` | None | Load parameters from a previous Scribble manifest file. |

### Notes

- Thresholds are calculated independently for each sample.
- Outlier cells are flagged in `adata.obs["mt_outlier"]`.
- Cells are not removed by this module; filtering occurs later in the workflow.
- QC statistics, thresholds, medians and MAD values are stored in `adata.uns["mt_qc"]`.
