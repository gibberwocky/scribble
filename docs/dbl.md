# dbl

## Purpose

The `dbl` module identifies potential doublets using one or both of the supported doublet detection methods:

- Scrublet
- scDblFinder

Doublet detection is performed independently for each sample. Cells identified by either selected method are flagged as doublets, but are not removed at this stage.

The module generates diagnostic plots, records per-sample doublet statistics, and produces an updated AnnData object for downstream filtering.

## Inputs

- AnnData object generated by the `import` and `mt` modules
- Raw counts stored in `adata.layers["counts"]`
- Sample assignments (`sample`)
- Mitochondrial outlier calls (`mt_outlier`)

## Outputs

- `<input>_dblqc.h5ad`
- Per-sample doublet score distributions
- Global doublet QC plot
- Doublet summary TSV
- Module manifest

## Main Functions

- Run Scrublet and/or scDblFinder per sample
- Store doublet scores and classifications
- Create a combined doublet call (`doublet_outlier`)
- Generate diagnostic plots
- Calculate per-sample doublet statistics
- Generate QC retention statistics
- Export a doublet summary table
- Create an updated AnnData object

## Parameters

### Required Parameters

| Parameter | Description |
|------------|-------------|
| `--project_dir` | Root Scribble project directory. |
| `--input` | Input AnnData object, typically the output from the `mt` module. |

### Doublet Detection Methods

At least one method must be enabled.

| Parameter | Default | Description |
|------------|----------|-------------|
| `--scrublet` | Disabled | Run Scrublet doublet detection. |
| `--scdblfinder` | Disabled | Run scDblFinder doublet detection. |

### Scrublet Parameters

| Parameter | Default | Description |
|------------|----------|-------------|
| `--scrublet_expected` | 0.07 | Expected doublet fraction used by Scrublet. |
| `--normalize` | False | Normalise and log-transform counts before running Scrublet. |

### Sample Handling

| Parameter | Default | Description |
|------------|----------|-------------|
| `--min_cells` | 200 | Minimum cells required in a sample before doublet detection is performed. Samples below this threshold are skipped. |

### Reproducibility

| Parameter | Default | Description |
|------------|----------|-------------|
| `--manifest` | None | Load parameters from a previous Scribble manifest file. |

### Notes

- Doublet detection is performed independently for each sample.
- Scrublet scores are converted to doublet calls using a sample-specific quantile threshold based on the expected doublet fraction; Scrublet scores exceeding this threshold are classed as outliers (rather than applying Scrublet's auto threshold).
- scDblFinder is executed through R using the SingleCellExperiment framework.
- Cells identified by either enabled method are flagged as `doublet_outlier`.
- Cells are not removed by this module; filtering occurs later in the workflow.
- A per-sample summary table and diagnostic plots are generated automatically.
