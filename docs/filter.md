# filter

## Purpose

The `filter` module removes low-quality cells from the dataset using the QC metrics generated by previous workflow stages.

Cells can be removed based on:

- Mitochondrial outlier status
- Doublet classification
- Minimum detected genes
- Maximum detected genes

Filtering can be applied globally or using sample-specific thresholds (currently only for --mingenes and --maxgenes) loaded from an Excel workbook.

The output is a filtered AnnData object that is used for downstream dimensionality reduction, integration, clustering, and annotation.

## Workflow Position

```text
import
  ↓
mt
  ↓
dbl
  ↓
pca
  ↓
filter
  ↓
preintegration
  ↓
harmony
  ↓
cluster
```

## Inputs

- AnnData object processed by the `mt` and `dbl` modules
- Mitochondrial outlier calls (`mt_outlier`)
- Doublet classifications (user-specified column)
- Gene count metrics (`n_genes_by_counts`)
- Optional sample-specific filter workbook

## Outputs

- `<input>_filtered.h5ad`
- Per-sample filtering summary TSV
- Module manifest

## Main Functions

- Load global or sample-specific filtering thresholds
- Construct mitochondrial, doublet, and gene-count filters
- Apply combined filtering criteria
- Generate per-sample retention statistics
- Export filtering summary tables
- Create a filtered AnnData object for downstream analysis

## Parameters

### Required Parameters

| Parameter | Description |
|------------|-------------|
| `--project_dir` | Root Scribble project directory. |
| `--input` | Input AnnData object, typically the output from the `dbl` module. |

### Gene Count Filtering

| Parameter | Default | Description |
|------------|----------|-------------|
| `--doublets` | doublet_outlier | Name of the doublet classification column in `adata.obs` to use for filtering (e.g. `doublet_outlier`, `scrublet_doublet`, or `scdblfinder_doublet`). |
| `--mingenes` | 200 | Minimum number of detected genes required for a cell to be retained. |
| `--maxgenes` | 6000 | Maximum number of detected genes allowed for a cell to be retained. |

### Sample-Specific Thresholds

| Parameter | Default | Description |
|------------|----------|-------------|
| `--filter_xlsx` | None | Excel workbook containing sample-specific filtering thresholds. |

If supplied, the workbook must contain a sheet named:

```text
filters
```

with columns:

```text
sample
min_genes
max_genes
```

These thresholds override the global `--mingenes` and `--maxgenes` values for matching samples.

### Reproducibility

| Parameter | Default | Description |
|------------|----------|-------------|
| `--manifest` | None | Load parameters from a previous Scribble manifest file. |

### Notes

- Cells fail filtering if they are:
  - mitochondrial outliers (`mt_outlier`)
  - doublets (`--doublets`)
  - below `min_genes`
  - above `max_genes`
- Filtering is performed independently for each sample when a filter workbook is supplied.
- Filtering doublets with the `doublet_outlier` removes outliers flagged by either Scrublet or scDblFinder.
- A summary TSV containing cell retention statistics is generated automatically.
- Filtered cells are permanently removed from the output AnnData object.
