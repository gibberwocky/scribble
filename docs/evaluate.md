# evaluate

## Purpose

The `evaluate` module reviews clustering results and generates recommendations for cluster curation.

Using cluster stability, sample mixing, cluster size, and reassignment behaviour, it classifies clusters as candidates to:

- keep
- merge
- subset
- investigate as potential trajectories
- flag for sample bias

The output is a decision table that guides manual cluster refinement and curation.

## Inputs

- Cluster summary table generated by the `cluster` module
- Clustered AnnData object
- Cluster stability metrics
- Reassignment statistics
- Sample entropy metrics
- Connectivity graph

## Outputs

- Cluster curation decision table (`*_decisions.tsv`)
- Optional clustering comparison table when multiple summaries are evaluated
- Suggested merge groups
- Module manifest

## Main Functions

- Evaluate cluster quality using stability and entropy metrics
- Identify clusters that may require subclustering
- Identify clusters that may represent continuous trajectories
- Detect clusters with strong reassignment behaviour
- Suggest merge candidates
- Analyse graph connectivity between clusters
- Create merge groups
- Produce a curator-facing decision report
- Support comparison of multiple clustering runs

## Parameters

### Required Parameters

| Parameter | Description |
|------------|-------------|
| `--project_dir` | Root Scribble project directory. |
| `--input` | Cluster summary table generated by the `cluster` module. May be a single file or multiple files for clustering comparison. |

### Cluster Evaluation Thresholds

| Parameter | Default | Description |
|------------|----------|-------------|
| `--min_cells` | 200 | Minimum cells required before a cluster is considered for further evaluation. Smaller clusters are retained by default. |
| `--large_cluster_fraction` | 0.15 | Clusters larger than this fraction of the dataset are flagged for possible subclustering. |
| `--low_stability` | 0.75 | Stability threshold below which clusters are considered potential trajectory or continuum populations. |
| `--high_stability` | 0.95 | Reference threshold used when interpreting highly stable clusters. |
| `--low_entropy` | 0.50 | Sample entropy threshold used to identify sample-biased clusters. |
| `--high_reassignment` | 0.30 | Reassignment threshold used to identify clusters that may require merging. |

### Merge Detection

| Parameter | Default | Description |
|------------|----------|-------------|
| `--merge_percentile` | 90 | Connectivity percentile used when identifying graph-based merge candidates. |

### Behaviour

| Parameter | Default | Description |
|------------|----------|-------------|
| `--ignore_saved_params` | False | Ignore clustering parameters stored in the AnnData object and use CLI values instead. |

### Reproducibility

| Parameter | Default | Description |
|------------|----------|-------------|
| `--manifest` | None | Load parameters from a previous Scribble manifest file. |

### Notes

- Clusters can be classified as `keep`, `merge`, `subset`, `trajectory`, or `flag_bias`.
- Merge suggestions are based on both reassignment statistics and graph connectivity.
- Multiple clustering summaries can be supplied and automatically ranked.
- Clustering quality is assessed using stability, entropy, reassignment burden, and cluster count.
- The output is intended to guide manual cluster curation rather than perform automatic refinement.
