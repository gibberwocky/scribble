# DGE report

## Purpose

The `DGE report` script generates an interpretation-focused report from the outputs of the `DGE compare` workflow.

It does not perform differential expression or pathway enrichment analysis itself. Instead, it filters, ranks, summarises, and visualises comparison results to highlight biologically meaningful and reproducible findings across analyses.

The module produces consolidated tables, heatmaps, concordance plots, leading-edge analyses, and a self-contained HTML report suitable for interpretation and reporting.

## Workflow Position

```text
annotate
  ↓
DGE
  ↓
DGE compare
  ↓
DGE report
```

## Inputs

- DGE comparison directory generated by `DGE compare`
- Differential expression comparison tables
- GSEA comparison tables
- Concordance metrics
- Leading-edge gene information

## Outputs

- HTML interpretation report
- Gene interpretation tables
- Pathway interpretation tables
- Leading-edge gene summaries
- Concordance plots
- Gene effect-size heatmaps
- Pathway enrichment heatmaps
- Report manifest

## Main Functions

- Apply reporting thresholds to DE and GSEA comparison results
- Classify concordant and discordant findings
- Highlight subset-specific effects
- Summarise reproducible differential expression signals
- Summarise reproducible pathway enrichment signals
- Identify recurrent leading-edge genes across analyses
- Generate concordance visualisations
- Generate gene and pathway heatmaps
- Produce a publication-style HTML report
- Export interpretation-ready summary tables

## Parameters

### Required Parameters

| Parameter | Description |
|------------|-------------|
| `--comparison_dir` | Output directory generated by the `DGE compare` workflow. |
| `--reference_analysis` | Primary analysis used as the reference for interpretation. |
| `--analyses` | Analyses to include in the report, listed in display order. |
| `--report_name` | Name assigned to the interpretation report. |

### Gene Reporting Thresholds

| Parameter | Default | Description |
|------------|----------|-------------|
| `--fdr` | 0.05 | FDR threshold used when surfacing results in the report. |
| `--nominal_p` | 0.05 | Nominal p-value threshold used for supporting evidence. |
| `--min_abs_log2fc` | 0.5 | Minimum absolute log2 fold change considered biologically meaningful. |
| `--min_abs_stat` | 2.0 | Minimum absolute test statistic required for report inclusion. |
| `--min_delta_log2fc` | 0.5 | Minimum difference in log2 fold change required to classify a result as meaningfully discordant. |

### Pathway Reporting Thresholds

| Parameter | Default | Description |
|------------|----------|-------------|
| `--min_abs_nes` | 1.5 | Minimum absolute normalised enrichment score (NES) considered biologically meaningful. |
| `--min_delta_nes` | 0.5 | Minimum NES difference required to classify pathway discordance. |

### Cross-Analysis Support

| Parameter | Default | Description |
|------------|----------|-------------|
| `--min_supporting_analyses` | 2 | Minimum number of supporting analyses required for a result to be considered concordant. |
| `--concordance_fdr` | 0.2 | Concordance threshold used by the upstream DGE comparison workflow. Must match the value used in `DGE compare`. |

### Output Display Limits

| Parameter | Default | Description |
|------------|----------|-------------|
| `--top_genes` | 20 | Maximum genes displayed per report category. |
| `--top_pathways` | 15 | Maximum pathways displayed per report category. |
| `--heatmap_genes` | 25 | Maximum genes shown in concordance heatmaps. |
| `--heatmap_pathways` | 25 | Maximum pathways shown in pathway heatmaps. |

### Plot Generation

| Parameter | Default | Description |
|------------|----------|-------------|
| `--make_plots` | True | Generate concordance plots and heatmaps. |

### Leading Edge Analysis

| Parameter | Default | Description |
|------------|----------|-------------|
| `--leading_edge_min_analyses` | 2 | Minimum analyses in which a leading-edge gene must recur to be reported. |
| `--leading_edge_min_pathways` | 2 | Minimum pathways in which a leading-edge gene must occur to be reported. |
| `--top_leading_edge_genes` | 25 | Maximum recurrent leading-edge genes shown per cell type. |
| `--leading_edge_nonribosomal_genes` | 15 | Maximum non-ribosomal leading-edge genes displayed per direction. |
| `--leading_edge_ribosomal_genes` | 5 | Maximum ribosomal leading-edge genes displayed per direction. |

### Notes

- This module does not alter DE or GSEA results.
- All thresholds are interpretation and reporting thresholds only.
- Concordant results require agreement across multiple analyses, not merely statistical significance in a single analysis.
- Genes and pathways are classified into categories including:
  - `REFERENCE_HIT_CONCORDANT`
  - `MEANINGFUL_DISCORDANCE`
  - `SUPPORTED_SUBSET_HIT`
  - `POTENTIAL_SUBSET_SPECIFIC`
- Recurrent leading-edge analysis identifies genes repeatedly contributing to concordant enriched pathways across analyses.
- Outputs include CSV summaries, concordance plots, heatmaps, leading-edge analyses, and a standalone HTML interpretation report.
