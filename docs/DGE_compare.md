# DGE compare

## Purpose

The `DGE compare` script collates and compares differential expression and pathway enrichment results across multiple DGE analyses.

It combines DE and GSEA outputs generated by separate runs of the DGE workflow, generates unified comparison tables, and quantifies agreement between analyses using log2 fold-change and pathway-level concordance metrics.

The module is designed for sensitivity analyses, methodological comparisons, dataset comparisons, and biological replication studies.

## Workflow Position

```text
annotate
  ↓
DGE
  ↓
DGE compare
```

## Inputs

- Two or more completed DGE analysis directories
- Differential expression result tables
- Ranked gene lists
- GSEA pathway enrichment results
- DGE/GSEA summary tables

## Outputs

- Combined DE result tables
- Combined GSEA result tables
- Pairwise DE concordance statistics
- Pairwise pathway concordance statistics
- Per-cell-type comparison tables
- Analysis summary reports
- Comparison manifest

## Main Functions

- Aggregate outputs from multiple DGE analyses
- Compare differential expression results between analyses
- Compare pathway enrichment results between analyses
- Calculate Pearson and Spearman concordance statistics
- Quantify agreement in log2 fold-change direction
- Quantify agreement in pathway enrichment direction
- Generate reference-relative comparisons
- Export per-cell-type DE and GSEA comparison tables
- Produce summary reports for method and dataset benchmarking

## Parameters

### Required Parameters

| Parameter | Description |
|------------|-------------|
| `--analysis_dirs` | One or more completed DGE analysis directories to compare. |
| `--analysis_names` | Human-readable names corresponding to each analysis directory. Must be provided in the same order as `--analysis_dirs`. |
| `--annotation` | Annotation level to compare (e.g. `cell_type_major`, `cell_type_minor`). |
| `--reference_analysis` | Analysis used as the reference when calculating relative differences and concordance metrics. |
| `--comparison_name` | Name assigned to the comparison and used in output files. |
| `--outdir` | Output directory for comparison results. |

### Concordance Thresholds

| Parameter | Default | Description |
|------------|----------|-------------|
| `--concordance_fdr` | 0.20 | FDR threshold used when evaluating agreement of significant DE genes and enriched pathways between analyses. |
| `--min_logFC` | 0.5 | Minimum absolute log2 fold change required to be considered a biologically meaningful effect during concordance calculations. |
| `--concordance_pval` | 0.05 | Nominal p-value threshold used when assessing nominal DE concordance. |

### Notes

- All supplied analyses must contain complete DGE and GSEA outputs generated by the Scribble DGE workflow.
- `analysis_names` and `analysis_dirs` must have matching lengths.
- The reference analysis must also be listed in `analysis_names`.
- Differential expression concordance is assessed using:
  - Pearson correlation
  - Spearman correlation
  - nominal significance overlap
  - FDR-significant overlap
  - effect-size concordance
  - direction-of-change concordance
- GSEA concordance is assessed using:
  - pathway NES correlations
  - overlap of significant pathways
  - pathway direction agreement
- Outputs are produced both globally and separately for each cell type.
- A comparison manifest is generated automatically to record comparison settings and source analyses.
